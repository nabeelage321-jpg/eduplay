📊 DATABASE SCHEMA
════════════════════════════════════════════════════════════════════════════

TABLE: activities
┌─────────────────────────────────────────────────────────────────────┐
│ Column          │ Type      │ Details                               │
├─────────────────────────────────────────────────────────────────────┤
│ id              │ UUID      │ PRIMARY KEY, auto-generated          │
│ title           │ TEXT      │ Game title (required)                │
│ description     │ TEXT      │ Game description                     │
│ type            │ TEXT      │ quiz, flashcards, match-up, etc     │
│ subject         │ TEXT      │ Math, Urdu, English, Science, etc   │
│ grade           │ TEXT      │ pre-k, kg, 1, 2, etc                │
│ language        │ TEXT      │ en, ur, ar, etc (default: en)      │
│ curriculum      │ TEXT      │ Pakistani, etc                       │
│ content         │ JSONB     │ Questions + options                  │
│ is_public       │ BOOLEAN   │ Public/Private (default: true)      │
│ play_count      │ INTEGER   │ Number of plays (default: 0)        │
│ created_at      │ TIMESTAMP │ Auto-set on insert                  │
│ updated_at      │ TIMESTAMP │ Auto-update on changes              │
└─────────────────────────────────────────────────────────────────────┘

INDEXES:
├── idx_activities_grade
├── idx_activities_subject
├── idx_activities_type
├── idx_activities_is_public
├── idx_activities_created_at (DESC)
└── idx_activities_subject_grade
